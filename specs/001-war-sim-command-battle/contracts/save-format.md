# 存档格式契约

遵循宪法第 13 条（存档版本化 + 迁移）。

## 布局

```text
magic:          "WFS-SAVE"（8 字节）
format_version: u32
header_json:    JSON（元数据：场景、tick、seed、threads、schema 版本、校验信息）
state_blob:     二进制/JSON 状态（完整可序列化，含统一 RNG 子流状态）
state_hash:     SHA-256（加载后校验，防损坏）
```

## 规则

- 破坏性变更必须递增 `format_version` 并提供迁移链（旧版本 → 新版本逐级迁移）；
- 加载时校验 magic、版本、哈希；校验失败明确报错，禁止静默恢复（宪法第 17 条）；
- 自动存档与手动存档分属各自槽位、互不覆盖；并发写入串行化（不产生半写存档）；
- 每个场景独立存档（教程不写入主游戏存档）；崩溃后提供"恢复最近自动存档"入口。
