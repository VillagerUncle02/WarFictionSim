# Data Model: 战争幻想模拟器 —— 核心玩法、指挥体系与战斗系统（Phase 1 输出）

> 基于 `spec.md` 的关键实体与状态机，字段为契约级定义；数值与公式以数据配置承载（宪法第 12 条）。

## 1. 指挥节点 / 指挥官

- 层级：连排级 / 营级 / 旅级（旅级后置接入）
- 归属：玩家接管或 AI 指挥官；可配备参谋 AI（营级及以上）
- 属性：指挥上限、协调能力、受训程度、服役时长、战斗经验
- 关联：指挥树（父节点 = 上级指挥官，子节点 = 下级指挥官）；资源池（派系模板定义）
- 状态机：待命 → 受令 → 决策中 → 已下达；被消灭/失能（按规模：连排级失败；营级可同级切换）

## 2. 编制单位

- 层级：班 → 排 → 连 → 营 → 旅（编制层级，用于自定义与资源池）
- 类型约束：步兵排仅步兵班；装甲排仅装甲车辆；合成排可混成且要求最低兵员能力；连/营/旅递归
- 协调能力：按下级单位（班）计算，不按总人数

## 3. 最小可指挥单位 与 最小配备单位

- 最小可指挥单位：连排级为单辆载具或班组；营级为连排级单位（战术分队由配属力量临时构成）
- 最小配备单位：单个士兵、单辆车；用于自定义最小可指挥单位构成

## 4. 战术分队 / 功能组

- 构成：破障组、火力组、突击组、保障组等（跨行政编制临时组合）
- 生命周期：按任务组建 → 执行 → 任务结束归建

## 5. 士兵

- 属性：武器、防护（头盔/轻重防弹衣）、经验三维（受训程度、服役时长、战斗经验）
- 状态：正常、压制、失联、伤亡、弹药；可泅渡（不携带重装备）
- 个人防护按个人尺度穿深公式结算（破片与小口径动能）

## 6. 载具

- 组成：底盘、武器、附加装甲、光电设备、乘员防护与训练
- 防护：前/侧/上/底四个方向；动能防护与化学能防护；可配置防弹衬层
- 模块状态：移动系统、光电观瞄系统、装填系统（部分有自动装弹机）
- 状态机：正常 → 模块受损（机动/观瞄/装填降级或瘫痪）→ 严重受损可弃车 → 被摧毁（乘员按规则伤亡/弃车转徒步）
- 载员：乘员编制 + 搭乘步兵容量（随自定义配置）

## 7. 班组

- 构成：士兵（N 人）、占地半径（队形决定）、平均防护、掩蔽状态
- 区域目标结算：期望伤亡 = N × 覆盖率；装备有最低操作人数，人员损失导致装备不可用或降效

## 8. 武器与弹药

- 弹药双属性：对甲（穿深、基准伤害）、对人员（破片/冲击波半径、杀伤力）
- 类型：动能（距离衰减）、化学能（穿深固定、伤害有上限）；基础特种弹药（烟幕等）
- 弹药会打空，需补给

## 9. 设施类单位 与 功能设施

- 设施类单位：指挥部、野战机场、补给点（玩家可部署，可被发现/攻击/构筑）
- 功能设施：医院、发电站、民用通讯设施、火车站、聚居点等（天然存在于地图）
  - 医院：提升后送效率
  - 发电站/通讯设施：断电/失效按电网连接关系传播，影响相连设施与居民协作
  - 占领可利用功能；可被摧毁，工兵可修复
- 制高点：建筑/山丘等地理地形，影响观察与射击

## 10. 地形要素

- 四类：基础地形（地势/河流/湖泊/沼泽/平原）、地表覆盖（树林/草丛）、人工地物（建筑/工事/公路/桥梁）、环境状态（天气/光照）
- 效果：移动速度/通行限制（沼泽减速、深水需桥梁或两栖）、掩蔽（阻挡伤害与射击）、隐蔽（降低被发现概率）

## 11. 任务

- 结构：类型、目标（点选/框选）、完成条件、意图/附加说明（自由文本）、结构化行为参数（接敌策略、谨慎程度等）、优先级、时限
- 分层：主任务、次要任务（进攻后扩大战果、附带歼灭目标）、持续任务（观察哨/巡逻，接到新命令前循环）
- 类型（13 种，v1 全量）：移动、巡逻、攻击、防守、控制区域、清剿、驱逐、构筑工事、隐蔽侦察、渗透侦察、观察哨、火力侦察、支援请求；可扩展（数据驱动）
- 状态机：下达 → 执行中 → 完成/失败/超时/被取消；持续任务循环；失败后可配置处置（如撤退至指定区域）；单位支持任务序列/列表（分支条件按优先级或配置顺序判定）
- 冲突仲裁：分支条件按优先级、未设置时按配置顺序；同优先级冲突命令按到达顺序，新命令取代旧命令并提示
- 待命：单位可在集结点待命、随时投入

## 12. 情报条目

- 内容：敌/己方位置与状态；最后已知状态 + 最后目视动向
- 来源标注：直属发现单位 / 同级经上级同步（额外标注）/ 更上级转发（只标层级）
- 识别分档：实际观察能力 = f(观察方能力、目标隐蔽、距离)；档位解锁数量 → 种类/构成；脱离识别需完全脱离视野一段时间
- 同步延迟：按层级定时同步，层级越高间隔越长；班组目视时实时更新

## 13. 派系模板

- 内容：各层级默认资源池清单、指挥风格参数（任务下发/执行倾向、配属审批简化度）、编制联动
- 三大派系：苏俄（指挥链+配属链）、北约（指挥链+任务链）、中国（内置合成化）
- 可自定义/扩展；分数配置独立
- 指挥风格参数取值空间由实现阶段补充（T052 以审批层级 0/1/2 落地，其余参数待登记，FR-006）

## 14. 支援请求 / 配属记录

- 请求：目标、需求类型、支援种类（含火力支援：营属迫击炮、大口径火炮、火箭炮；航空后置）
- 处置：配属 / 拒绝 / 转请；仲裁按（优先级, 到达序列号）
- 配属：临时移交指挥权，任务结束归建；配属型（工兵、随行医疗）可直接指挥但功能单一；支援型（补给/后送/维修/通信/侦察协调/防化）只有请求权，不能微管理
- 后勤：规划与管理归营级及以上；连排级为执行单元（物资运输、伤员后送）

## 15. 分数配置

- 自定义内容占用分数；步兵班与载具有分数上限
- 三级超限：Level 1 ≤ 110% 无惩罚 / Level 2 ≤ 125% 明确惩罚 / Level 3 > 125% 禁止保存（阈值以数据配置承载、可调，FR-020 实现基线）

## 16. 存档

- 格式：magic `WFS-SAVE` + `format_version` + `header_json` + `state_blob` + 迁移链 + 状态哈希
- 槽位：手动存档 + 定期自动存档（退出时保存；战斗开始/结算前不自动存档）；自动与手动并发串行化；崩溃后恢复最近自动存档入口
- 场景独立存档（教程不写入主游戏存档）

## 17. 事件与日志

- 事件日志：分类/严重级、环形保留（5000 条）、关键事件优先、过滤与搜索
- 事件日志查询经 C ABI 通道暴露（`wfs_sim_query_events`，contracts/sim-c-api.md）：
  过滤字段 = 分类 / 最低严重级 / 文本子串 / 数量上限；结果按 seq 升序返回，并携带
  截断前总条数（count）与截断标志（truncated）
- 决策日志（JSONL）：AI 决策点状态快照 + 输入 + 输出，供可复现性与复盘
