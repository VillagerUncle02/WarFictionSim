# notes（自动化审计记录）

本目录存放实现循环自动化产生的审计记录，**提交进仓库**，作为可追溯的审查轨迹。

## 目录约定

```
notes/
├── README.md       # 本文件
└── reviews/        # AI 审查记录（每轮一条）
    ├── <branch>-r1.md
    ├── <branch>-r2.md
    └── ...
```

## 命名规范

- 审查记录：`<分支名>-r<轮次>.md`，如 `feature-us1-mvp-r1.md`；
- 门禁失败记录（如产生）：`gates-<分支名>.md`。

## 内容要求

- 全部使用中文；
- 审查记录包含：审查范围、对比上一轮（已修复/回归/新增/无变化）、findings（级别/file:line/问题/修复方向/状态）、未验证猜测、整体结论与置信度、收敛检测与轮次提醒；
- 超过 3 轮的审查必须标注"轮次过多提醒"；连续 2 轮无改善必须标注"收敛异常提醒"。

## 用途

- 人工审查时可快速查看每轮发现与修复状态；
- AI 下一轮审查前读取最近一条记录，核对已修复项与回归；
- 作为实现循环的审计轨迹留存。
