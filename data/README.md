# data/ —— 数据驱动内容（宪法第 12 条：一切可自定义内容以数据定义，禁止硬编码）

## 约定

- 每个 JSON 数据文件必须携带 `"schema_version"` 字段；
- 加载时执行 schema + 语义校验，非法数据**报错而非崩溃**；
- 数据引用（单位/武器/地形/剧本目标）必须存在，否则校验失败。

## 目录

| 目录 | 内容 |
|---|---|
| `factions/` | 三大派系模板（资源池 + 指挥风格参数） |
| `scenarios/` | 剧本（营级对抗 + 连排级新手教程） |
| `units/` | 单位/武器/弹药/装备/工事 |
| `terrain/` | 地形/环境/功能设施 |
| `ai/` | AI 提示词与模型参数（随仓库版本管理） |
